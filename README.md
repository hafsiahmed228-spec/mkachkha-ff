# MKACHKHA FF 🎮

صانع شخصيات 3D واقعية + عالم تتحرّك فيه + ستوديو تصاور بالـ IA.

## 📲 حمّل الأبليكاسيون
👉 **[MKACHKHA-FF.apk](https://github.com/hafsiahmed228-spec/mkachkha-ff/releases/latest/download/MKACHKHA-FF.apk)**

## الميزات
- 👤 شخصيات 3D واقعية (skeleton كامل + حركات mocap: واقف، يمشي، يجري، يشطح…)
- 📥 تنجم تزيد شخصياتك (.glb متاع Mixamo / Ready Player Me)
- 🎨 ألوان اللبسة، ماسك، شاشية، كاسكيت، نظارات، نومرو و اسم على الضهر
- 🌍 مدن العالم: باريس، لندن، نيويورك، إيبيزا، تونس، دبي + بلايص اللعبة (نيون، الملعب، سيدي بوسعيد، البحر، السوق) + ليل/نهار
- 🎮 لوبي كيف الألعاب + 🤖 الـ IA تتحكّم في كل تفصيلة من الشخصية
- 🕺 19 بوز للتصاور (IK على الصبعان و اليدين)، لقطة مع صحابك، سيلفي، كادرات
- 📸 تصاور و 🎥 فيديوات بعلامة MKACHKHA FF
- ✨ ستوديو IA: تصاور واقعية بـ Gemini (Nano Banana) من الكادر 3D + وصف الشخصية + تصويرة وجهك
- 🗣️ الشخصيات تحكي + حوار بالـ IA

## تقني
Vite + three.js + Capacitor. الـ APK يتبنى وحدو بـ GitHub Actions.
